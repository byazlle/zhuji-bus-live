# 诸暨实时公交网页 - 项目需求与改动汇总

## 一、项目背景

**用户痛点**：
- 诸暨公交查询必须用浙里办APP，老人没有支付宝，登录困难
- 浙里办里有些线路（城乡公交）只有那里能查
- 想要一个免登录、打开就能用的网页

**后端API已解决**：
- API地址：`https://zjcx.zhuji.gov.cn:9443`
- 不需要登录，userToken固定写死为 "userToken"
- 支持CORS跨域，浏览器可以直接调用
- 共196条线路，包括城乡公交

## 二、产品需求（用户明确要求）

### 2.1 整体风格
- **老年人友好**：大字体、大按钮、操作简单
- **不要专业术语**：不要"上行/下行"，直接写终点站名称
- **简洁明了**：不要多余的东西

### 2.2 首页
- 上面是搜索框，输入线路号就能搜
- 下面是"我的常用线路"区域，收藏过的线路显示在这
- 再下面是全部线路列表
- 每条线路右边有星星，点一下就收藏/取消
- **收藏上限：30条**
- **默认不预置收藏**，用户自己选

### 2.3 线路详情页
- 顶部是方向切换，两个按钮分别显示两个方向的终点站
- 站点列表：**终点放最上面，起点放最下面**
- 点哪个站，哪个站就变成"你在这"（绿色高亮）
- 车辆卡片固定在顶部，滚动时一直能看到
- 车辆信息要写清楚：车现在在哪一站、还有几站到你这、预计几分钟

### 2.4 车辆显示规则
- 只显示还没超过你的车，已经开过的不显示
- 离你最近的那辆排第一，标个"最近"
- **分级自动刷新**：
  - 还有1站以内：10秒刷新一次
  - 还有2站：15秒刷新一次
  - 还有3站以上：60秒刷新一次
- 时间显示规则：
  - 已到站：写"已到站"
  - 还有1站：写"马上到"
  - 还有多站：写"约X分钟"

## 五、本轮校验与修复记录（2026-11-02）

### 5.1 代码位置
| 内容 | 路径 |
|---|---|
| 网页源码（唯一源头） | `web/index.html` |
| Android 壳工程 | `android/`（MainActivity + Manifest + 图标 + build.sh） |
| 打包产物 | `dist/诸暨实时公交.apk` |
| 自动化校验脚本 | `_test/test.js`、`_test/test2.js`、`_test/test3.js` |
| 构建工具链（JDK17 + Android SDK 34） | `_tools/`（重新打包只需跑 `bash android/build.sh`） |

### 5.2 已确认的接口事实（实测）
- `searchBusLines` 的 `lineName` 不能为空（返回 code 203），分页参数是 **`page` + `offset`**（`offset` 即每页条数），默认只返回 10 条
- 全部线路：`lineName="路"` 共 386 条（去重后），需翻 8 页
- `vehicleOrder` = 车**已经过**的站的 `stationOrder`（1 起），不是"下一站"
- `list[].distance` = 到**下一站**的米数
- `isArriveStation` = 0/1，配合 distance/段长可判断"正在本站"还是"已经离站"
- 接口 **`Access-Control-Allow-Origin: *`**，浏览器和 WebView 的 `file://` 页面都能直接调

### 5.3 修复清单
1. **方向箭头**：上下行按钮原来分别是 ↑ / ↓，但两个方向的列表都是"终点在最上"，车都是往上开 → 统一改为 ↑（并用 SVG 箭头保证清晰）
2. **车辆位置计算**：原来直接把 `vehicleOrder` 当站点下标（差 1 位，且没考虑"已离站"），改为 `剩余站数 = 我的站序 - 车已过站序`，`remain=0 且已走远` 判定为开过并隐藏
3. **选站后重算**：选站立即用本地缓存数据重算一次，再拉最新位置，不等网络；选站按站名跨方向记忆，下次打开自动恢复
4. **分级刷新**：`setInterval` 改为 `setTimeout` 链式调度；实测 0/1 站→10s，2 站→15s，≥3 站→60s；切后台暂停、回前台立即刷
5. **UI 紧凑**：车辆卡片单行化、去掉多余留白、方向按钮/定位条压缩，吸顶区高度从 **365px 降到 175px**（780 屏占 22%）
6. **滚动遮挡**：原来 `.bus-cards{position:sticky;top:105px}` 写死 105px 与真实头高不符 → 改为把顶栏+方向+定位+车辆卡片包在**一个 sticky 容器**里，`top:0`，彻底不存在遮挡/空隙
7. **顺带修掉的问题**（原版存在）：
   - 首页"全部线路"永远是空的（`lineName` 空串被接口拒绝 + 只取第一页 10 条）→ 改为内置 386 条数据 + 本地搜索 + 7 天后台刷新
   - `body{overflow-x:hidden}` 破坏 `position:sticky` 与页面滚动
   - 站点列表和车辆列表各请求一次接口（重复请求）且"车在这"标记与卡片算法不一致
   - 切方向时丢失"我在这"
   - 请求竞态：切方向后旧请求会覆盖新数据
   - 默认自动选中"中间站"，导致距离全部算错（现在必须由用户点选，未选时提示引导）
   - 收藏 30 条上限有 toast 但星标仍变亮（状态没回滚）
   - 无网络异常处理，失败后不再自动重试

### 5.4 已知限制
- APK 未在真机跑过（本机无 Android 设备/模拟器），但网页部分已在 Chrome 移动端视口（390/360/320 三档）全流程实测通过，APK 为原生 WebView 壳，签名/清单/资源均已校验
- `searchStation`（按站点找线路）未做进 UI

## 六、第二轮迭代（2026-11-02 下午）

### 6.1 方向栏：文字替代箭头
- 原来的 `↑ 终点站` 改成两行：`[发车] 起点站` + `[终点] 终点站`，标签做成小徽章
- 环线（起终点同名，如青春巴士夜间专线A）自动多显示一行 `经 XX` 区分

### 6.2 站点列表正序 / 倒序
- 表头 `站点列表（终点在最上面）` 右侧加两个分段按钮：`终点站在上`（蓝选中）/ `起点站在上`（灰未选）
- 括号文案跟着切换为"（起点在最上面）"；选择写进 localStorage（`zjbus.order`），下次进入沿用
- 切换后自动把"你在这"滚回视野
- 判定逻辑改为用升序下标比较（`idx < 我的下标` = 车已过），正倒序都正确

### 6.3 定位
- 手动：`我在这` 行右侧 `定位` 按钮，取 GPS 后按最近站点自动选中（>2km 提示手动选）
- 自动：仅当浏览器已授权定位时，进入线路静默选最近站，不弹框打扰
- 选站后立即重算车辆距离，并写入 `zjbus.mystation.v1`（按站名跨方向记忆）
- APK 侧：清单加 `ACCESS_FINE/COARSE_LOCATION`，`WebChromeClient` 处理 `onGeolocationPermissionsShowPrompt` + 运行时权限申请，`retain=true` 让下次可静默定位

### 6.4 刷新信息条移位
- 时间条移到标题 `1路` 右侧（`⟳ 16:56`），点它 = 立即刷新
- 原来的"刷新"按钮从"我在这"行移除，该行只剩定位信息 + 定位按钮
- 刷新分级维持实测结果：0~1 站 10s / 2 站 15s / ≥3 站或无车 60s；切后台暂停、回前台立即刷

### 6.5 发车表
- 方向栏最右侧加 `发车表` 入口（时钟图标）
- 底部弹层展示两个方向：开往哪 / 从哪发车 / 首班 / 末班 / 全程公里 / 站数 / 票价，当前方向标"当前"
- 数据全部来自 `queryLine` 的 `startFirst` / `startLast` / `lineLength` / `totalPrice`
- 点遮罩或"关闭"收起；安卓返回键优先关弹层

### 6.6 首页精简
- 删除副标题"不用登录 · 打开就能查"
- 删除"点 ☆ 收藏常用"提示，空态压缩为一行"点下面线路右边的 ☆ 收藏常用"
- 头部高度 70 → 47px，卡片/行间距整体收紧

### 6.7 字号调节
- 首页标题右侧 `缩小` / `放大` 两个按钮，5 档：90% / 100% / 112% / 124% / 136%
- 实现方式是 `body{zoom:var(--font-zoom)}`（布局级缩放，文字重新栅格化，清晰不虚），不是 `transform:scale`
- 到顶/到底自动置灰；档位存 `zjbus.zoom`
- 放大后为防止挤压：≥124% 时方向卡片自动改成上下堆叠、右侧发车表跨两行，车辆卡片只留最近 1 辆

### 6.8 其它修复
- `返回` 按钮被折成两行 → 箭头拆成独立元素 + `white-space:nowrap` + 去掉固定宽度
- 线路总数 386 → 395（补上"青春巴士夜间专线""高湖专线"等不含"路"字的线路），本地搜不到时再走接口兜底
- 安卓返回键改为统一走 `window.androidBack()`：先关弹层 → 再回首页 → 都没有才退出
